🔑 SHA-256 Hashing

Hashing is a one-way function. We take the certificate details and generate a 64-character "digital fingerprint".

Input $\rightarrow$ Hash(Data) $\rightarrow$ Fingerprint

🔗 Previous-Hash Linking

Every block contains the hash of the previous block. This creates a chain. If you change Block 1, Block 2's "previous hash" pointer becomes wrong.

Block N $\rightarrow$ contains $\rightarrow$ Hash(Block N-1)

🛡️ Tamper Detection

The system doesn't just check if the ID exists; it re-hashes the data and checks if that hash is anchored in the valid blockchain.
